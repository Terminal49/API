Coverage changes as carriers and terminals come online. This page records what was added to or removed from the live set, so you can audit coverage for your lanes over time.

For product and API changes, see the [API changelog](/updates/home).

<Update label="November 9, 2026" description="Wilmington (NC) removed from the public terminal table">
  **Status at this update: degraded.** Wilmington terminal data is unavailable; carrier-reported events remain available. No resolution date is confirmed.
  The public terminal table now lists 160 direct integrations, down from 161 on November 2.

  - Port of Wilmington Container Terminal (`L194`) is removed because we can't currently retrieve terminal data from the NC Ports portal. It will return to the table once terminal data is flowing again.
  - Containers discharging at Wilmington still show carrier-reported events.

  No API endpoint or schema changes are required.
</Update>

<Update label="November 2, 2026" description="Expanded terminal coverage worldwide">
  Track shipments across 161 directly connected terminals worldwide, including 26 APM facilities across the Americas, Europe, Africa, Asia, and the Middle East.

  - Expanded APM coverage includes Aarhus, Rotterdam Maasvlakte II, Tangier Med, Pipavav, Apapa, Moín, and more.
  - Coverage also includes PNIT in Busan, Boston Conley, North Charleston, Wando Welch, Hugh K. Leatherman, and Manzanillo International Terminal in Panama.
  - Seattle Terminal 30 and Shippers Transport Express in Oakland are no longer listed as supported. The Long Beach and Carson facilities remain supported.

  See the [full terminal list](/coverage/terminals) for pickup availability, last free day, holds, and movement milestones available at each location, along with connection requirements. No changes to your API integration are required.
</Update>

<Update label="October 14, 2026" description="Seaboard Marine added to the public carrier list">
  Seaboard Marine (`SMLU`) is now supported.

  - You can track Seaboard Marine shipments by bill of lading, booking number, or container number.
  - For bill of lading and booking lookups, enter the master bill of lading without the `SMLU` prefix.

  No API endpoint or schema changes are required.
</Update>

<Update label="October 9, 2026" description="New Zealand terminals added">
  The public terminal table now lists 138 direct integrations, up from 136 on September 15.

  - Lyttelton Port Company (`NZLYTLPC`) and Timaru Container Terminal (`NZTIUTCTL`) are live through PortConnect. Both report discharge, last free day, and pickup for import and coastal-feeder containers.
  - A New Zealand region filter is added to the terminal table.
  - Auckland and Tauranga are not yet supported at the terminal level.

  No API endpoint or schema changes are required.
</Update>

<Update label="September 15, 2026" description="Terminal coverage refreshed from production">
  The public terminal table now lists 136 direct integrations, up from 102 on August 14.

  - 12 Australian terminal integrations are public defaults across Adelaide, Brisbane, Fremantle, Melbourne, and Sydney.
  - 26 global terminal integrations have shipped. They add 24 terminals to the public table because the two Jeddah integrations are additional sources for terminals that were already listed.
  - PortConnect integrations for Lyttelton and Timaru shipped but remain disabled and non-default pending commercial entitlement and production credentials. They are not included in the public terminal table.

  No API endpoint or schema changes are required.
</Update>

<Update label="August 14, 2026" description="Coverage list published from production">
  First publication of the live coverage list, generated directly from production integrations.

  **Ocean carriers**
  - 36 shipping lines in the public default set, trackable by bill of lading, booking, or container number
  - Account-enabled carriers listed separately: Seaboard Marine (`SMLU`) and Trailer Bridge (`TRBR`)
  - Newly documented lines that were missing from the previous list: KMTC (`KMTU`), World Direct Shipping (`WDSB`), and SeaLead (`SQQY`)

  **Ports & terminals**
  - 102 container terminals live, searchable by port, UN/LOCODE, and FIRMS code
  - Newly documented coverage that was missing from the previous list, including Montreal, Mexico, Felixstowe, Wilmington (NC), Hong Kong, Jebel Ali, Hamburg, Livorno, Dammam, Jeddah, Salalah, Barcelona, Naples, Chittagong, Gdynia, Guayaquil, and Umm Qasr
  - Removed from the supported list: Boston (Conley), Saint John, Fraser Surrey, and Florida International Terminal (Port Everglades Terminal remains supported)

  **Rail carriers**
  - All six North American Class I railroads confirmed live: BNSF, CN, CP, CSX, Norfolk Southern, and Union Pacific
</Update>

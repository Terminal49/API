title: "Get a vessel by ID"
description: "Retrieve a vessel on your actively tracked shipments by its Terminal49 vessel ID, including name, IMO number, and current position. Requires Routing Data."
og:title: Get a Vessel by ID | Terminal49 API
og:description: Retrieve vessel details by Terminal49 resource ID. Returns the vessel name, IMO number, current position, flag, and linked shipment information.
openapi: get /vessels/{id}
---

<Note>
  This is a paid Routing Data endpoint. It returns only vessels on your account's actively tracked shipments. See [Vessel data access](/api-docs/useful-info/entitlements#vessel-data-access) for the `401`, `403`, and `404` responses.
</Note>

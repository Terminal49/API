openapi: get /tracking_requests/{tracking_request_id}/party_roles
---

Returns every party role on the tracking request. The linked parties are returned in `included`.

## Path parameters

| Parameter | Required | Description |
|-----------|----------|-------------|
| `tracking_request_id` | Yes | The ID of the tracking request |

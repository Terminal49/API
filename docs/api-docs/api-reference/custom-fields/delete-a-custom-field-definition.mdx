Delete a custom field definition by its ID.

## Path parameters

| Parameter | Description |
|-----------|-------------|
| `id` | The unique identifier of the custom field definition |

## Behavior

Returns `204` when the definition is deleted.

- A definition that has values returns `422` with the title `This field has data. You can archive it instead.`
- Templates are managed by Terminal49. Other accounts get `401` when they delete a template.
- For a Terminal49 account, a template that other accounts use returns `422` with the title `This template is in use by other accounts. You can archive it instead.`

Lists the custom field definitions configured for your account. The list is not paginated. The API ignores `page[number]` and `page[size]` and returns every row, but still sends pagination `links`. Do not follow `links.next`.

The API always returns the definitions of the authenticated user's account, whatever `account_id` you pass.

## Query filters

| Filter | Description |
|--------|-------------|
| `filter[entity_type]` | Filter by entity type: `Shipment` or `Cargo` (containers) |
| `filter[data_type]` | Filter by data type |
| `filter[display_name]` | Filter by display name (prefix match) |

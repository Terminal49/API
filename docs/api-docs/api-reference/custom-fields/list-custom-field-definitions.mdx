Lists the Terminal49 template definitions. It does not return the definitions configured for your account. To list those, use [List account custom field definitions](/api-docs/api-reference/custom-fields/list-account-custom-field-definitions).

## Query filters

| Filter | Description |
|--------|-------------|
| `filter[entity_type]` | Filter by entity type: `Shipment` or `Cargo` (containers) |
| `filter[data_type]` | Filter by data type |
| `filter[display_name]` | Filter by display name (prefix match) |

The SDK exposes a `Terminal49Client` with methods grouped by resource type. Each method corresponds to an [API endpoint](/home).

## Resource namespaces (recommended)

### Search

| Method | Description |
|--------|-------------|
| `client.search(query)` | Search across shipments and containers by number, reference, or keyword |

### Shipments

| Method | Description |
|--------|-------------|
| `client.shipments.get(id, includeContainers?, options?)` | Fetch a shipment by ID. Set `includeContainers: false` to omit container relationships. |
| `client.shipments.list(filters?, options?)` | List shipments matching filter criteria. |
| `client.shipments.update(id, attrs, options?)` | Update shipment attributes like reference numbers or tags. |
| `client.shipments.stopTracking(id, options?)` | Stop tracking a shipment and its containers. |
| `client.shipments.resumeTracking(id, options?)` | Resume tracking a previously stopped shipment. |
| `client.shipments.customFields(id, options?)` | `GET /shipments/{id}/custom_fields`. List the custom field values set on the shipment, with their definitions. |
| `client.shipments.setCustomField(id, apiSlug, value, options?)` | `POST /shipments/{id}/custom_fields`. Set a custom field value on the shipment. |
| `client.shipments.updateCustomField(id, apiSlug, value, options?)` | `PATCH /shipments/{id}/custom_fields/{api_slug}`. Update an existing custom field value on the shipment. |
| `client.shipments.deleteCustomField(id, apiSlug, options?)` | `DELETE /shipments/{id}/custom_fields/{api_slug}`. Remove a custom field value from the shipment. |
| `client.shipments.partyRoles(id, options?)` | `GET /shipments/{id}/party_roles`. List the party roles assigned to the shipment. |
| `client.shipments.addPartyRole(id, { role, partyId }, options?)` | `POST /shipments/{id}/party_roles`. Assign a party to the shipment in the given role. |
| `client.shipments.removePartyRole(id, partyRoleId, options?)` | `DELETE /shipments/{id}/party_roles/{id}`. Remove a party role assignment from the shipment. |

### Containers

| Method | Description |
|--------|-------------|
| `client.containers.get(id, include?, options?)` | Fetch a container by ID. `include` is an array of related resources. |
| `client.containers.list(filters?, options?)` | List containers matching filter criteria. |
| `client.containers.events(id, options?)` | Get transport events for a container. |
| `client.containers.route(id, options?)` | Get the container's route from `GET /containers/{id}/map_geojson`. `raw` returns the GeoJSON FeatureCollection. `mapped` returns `{ ports, currentVessel, totalPorts }`, with ports in route order and their arrival and departure times. Requires the Routing Data feature. `client.containers.map` is deprecated. It returns the GeoJSON FeatureCollection without mapping, so `both` returns `{ raw, mapped }` with the FeatureCollection in each half. |
| `client.containers.rawEvents(id, options?)` | Get unprocessed events as received from carriers. |
| `client.containers.refresh(id, options?)` | Request an immediate data refresh from the carrier. |
| `client.containers.update(id, attrs, options?)` | `PATCH /containers/{id}`. Update container attributes such as `ref_numbers`. |
| `client.containers.customFields(id, options?)` | `GET /containers/{id}/custom_fields`. List the custom field values set on the container, with their definitions. |
| `client.containers.setCustomField(id, apiSlug, value, options?)` | `POST /containers/{id}/custom_fields`. Set a custom field value on the container. |
| `client.containers.updateCustomField(id, apiSlug, value, options?)` | `PATCH /containers/{id}/custom_fields/{api_slug}`. Update an existing custom field value on the container. |
| `client.containers.deleteCustomField(id, apiSlug, options?)` | `DELETE /containers/{id}/custom_fields/{api_slug}`. Remove a custom field value from the container. |
| `client.containers.partyRoles(id, options?)` | `GET /containers/{id}/party_roles`. List the party roles assigned to the container. |
| `client.containers.addPartyRole(id, { role, partyId }, options?)` | `POST /containers/{id}/party_roles`. Assign a party to the container in the given role. |
| `client.containers.removePartyRole(id, partyRoleId, options?)` | `DELETE /containers/{id}/party_roles/{id}`. Remove a party role assignment from the container. |

## Common options

Most methods accept an `options` object with `format`:

```typescript
const shipment = await client.shipments.get('shipment-id', true, {
  format: 'mapped',
});
```

Supported formats:

- `raw` (default) returns the JSON:API response
- `mapped` returns simplified objects for methods that support mapping
- `both` returns `{ raw, mapped }`

You can set a default format when initializing the client:

```typescript
const client = new Terminal49Client({
  apiToken: process.env.T49_API_TOKEN!,
  defaultFormat: 'mapped',
});
```

List methods also accept pagination options:

```typescript
const shipments = await client.shipments.list({}, {
  page: 1,
  pageSize: 25,
  format: 'mapped',
});
```

See [Filtering & Pagination](/sdk/filtering-pagination) for details.

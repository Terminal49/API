# Interface: CurrentCredential

Mapped `GET /me` response: the credential behind the current request.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-account"></a> `account` | [`CurrentAccount`](/sdk/reference/types/models/interfaces/CurrentAccount) | - |
| <a id="property-channel"></a> `channel` | `string` | api, dashboard, mcp, or askt49. |
| <a id="property-features"></a> `features` | `Record`\<`string`, [`FeatureAvailability`](/sdk/reference/types/models/interfaces/FeatureAvailability)\> | - |
| <a id="property-id"></a> `id` | `string` | The API key id or the user id, depending on `kind`. |
| <a id="property-kind"></a> `kind` | `"api_key"` \| `"user"` | - |
| <a id="property-name"></a> `name?` | `string` | API key label; undefined for user tokens. |
| <a id="property-user"></a> `user` | [`CurrentUser`](/sdk/reference/types/models/interfaces/CurrentUser) \| `null` | `null` for an API key that is not acting as a user. |

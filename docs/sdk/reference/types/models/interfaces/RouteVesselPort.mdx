# Interface: RouteVesselPort

A port the current vessel left or is heading to, as the `current_vessel` feature names it.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-label"></a> `label` | `string` \| `null` | `POL`, `POD`, or `TS1`, `TS2`, and so on for transshipment ports. |
| <a id="property-locationid"></a> `locationId` | `string` \| `null` | Matches [RoutePort.locationId](/sdk/reference/types/models/interfaces/RoutePort#property-locationid) of the same port. |
| <a id="property-name"></a> `name` | `string` \| `null` | - |

# Interface: TrackingSlots

Tracking-slot usage on free and trial plans.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-activecontainers"></a> `activeContainers?` | `number` | Slots held by containers currently being tracked. |
| <a id="property-limit"></a> `limit` | `number` | Slots the plan allows. |
| <a id="property-pendingtrackingrequests"></a> `pendingTrackingRequests?` | `number` | Slots reserved by tracking requests that have not resolved yet. |
| <a id="property-remaining"></a> `remaining` | `number` | Slots still available, never below zero. |
| <a id="property-used"></a> `used` | `number` | Slots in use: active containers plus pending requests, deduplicated by container number. |

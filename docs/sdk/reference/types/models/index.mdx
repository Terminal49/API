# types/models

## Interfaces

| Interface | Description |
| ------ | ------ |
| [Container](/sdk/reference/types/models/interfaces/Container) | Simplified container model returned by mapped SDK responses. |
| [ContainerRoute](/sdk/reference/types/models/interfaces/ContainerRoute) | Mapped container route: ports in route order plus the current vessel. |
| [CurrentAccount](/sdk/reference/types/models/interfaces/CurrentAccount) | An account as `GET /me` describes it. |
| [CurrentCredential](/sdk/reference/types/models/interfaces/CurrentCredential) | Mapped `GET /me` response: the credential behind the current request. |
| [CurrentUser](/sdk/reference/types/models/interfaces/CurrentUser) | The signed-in user as `GET /me` describes them. |
| [CustomField](/sdk/reference/types/models/interfaces/CustomField) | Account-defined custom field value on a container, shipment, or tracking request. |
| [FeatureAvailability](/sdk/reference/types/models/interfaces/FeatureAvailability) | Availability of one gated feature for the current credential on the current account. |
| [PaginatedResult](/sdk/reference/types/models/interfaces/PaginatedResult) | Mapped list response containing records plus pagination metadata. |
| [PaginationLinks](/sdk/reference/types/models/interfaces/PaginationLinks) | Pagination links returned by Terminal49 list endpoints. |
| [RouteCoordinates](/sdk/reference/types/models/interfaces/RouteCoordinates) | A `[longitude, latitude]` GeoJSON point, named so the axis order cannot be swapped. |
| [RoutePort](/sdk/reference/types/models/interfaces/RoutePort) | One port on a container route, from a `port` feature of `GET /containers/{id}/map_geojson`. |
| [RouteVessel](/sdk/reference/types/models/interfaces/RouteVessel) | The vessel carrying the container right now. Present only while it is at sea. |
| [RouteVesselPort](/sdk/reference/types/models/interfaces/RouteVesselPort) | A port the current vessel left or is heading to, as the `current_vessel` feature names it. |
| [Shipment](/sdk/reference/types/models/interfaces/Shipment) | Simplified shipment model returned by mapped SDK responses. |
| [ShippingLine](/sdk/reference/types/models/interfaces/ShippingLine) | Simplified shipping line returned by mapped SDK responses. |
| [TrackingRequest](/sdk/reference/types/models/interfaces/TrackingRequest) | Simplified tracking request model returned by mapped SDK responses. |
| [TrackingSlots](/sdk/reference/types/models/interfaces/TrackingSlots) | Tracking-slot usage on free and trial plans. |

## Type Aliases
